Strict モードを有効にすると、 危険な動作や潜在的せんざいてきなエラーがある挙動の一部は完全に禁止されます。

JavaScript の class は、クラス宣言（Class Declaration） または クラス式（Class Expression） として定義できます。function や let、const と同じに、構造を宣言するものに分類されます。
—--------ví dụ về instance methods—-----------
例えば、このようなコードがあります。
class Car {
constructor(name, year) {
this.name = name;
this.year = year;
}
// Instance method
getAge() {
const age = new Date().getFullYear() - this.year;
return `${this.name} is ${age} years old.`;
}
}
クラスの作り方の構文については、ドキュメントの中でも、すでに説明されています。
つまり、Classというキーワードがあります。これは、クラス名です。次は、｛｝です。｛｝の中には、Classの処理です。
このconstructorがあり、このメソッド (getAge)があります。
constructorのコードとは、このクラスの対象を初期化するためです。name と year という 2 つのパラメータを受け取って、オブジェクトのプロパティに代入します。
getAge()とは、オブジェクトのメソッドです。インスタンスメソッドです。
このメソッドの機能は、現在の年と yearのパラメータ をもとに車の年齢を計算して、その車の年齢を表す文字列を返します。
new Date().getFullYear()　これは、現在の年を取得する構文ですね。これは、引き算ですね。
return `${this.name} is ${age} years old.`;　これは、その車の年齢を返すコードです。
では、このクラスを実行するために、ここでは、このように、 2 つの対象変数を新しく初期化して、パラメータを渡します。

次は、JavascriptのRegex部分です。つまり、正規表現（せいきひょうげん）の部分ですね。
Regex（正規表現）は、文字列の検索、確認、または置換を行うために使用されます。
実行するには、２つの書き方があります。
方法１は、このようです。let regex1 = /\d+/g;
この方法では、\d+の部分は、パータンと呼ばれます。gの部分は、フラグと呼ばれます。
各パータンと、各フラグの意味は、資料でも書いています。
２つ目の書き方は、このようにします。let regex2 = new RegExp("\\d+", "g");
同じように、これは、パータンです。これは、フラグです。
そして、よく使われる方法は、方法１です。つまり、これです。理由は、読みやすくて理解しやすいためです。
—--------------ví dụ thực tế 1—-----------
let regex1 = /\d+/g;
let text = "Number phone: 0123-456-789";
console.log("Test regex1: ", text.match(regex1));
例えば、このような例があります。
この例のコンソールログの結果は、3つの値を持つ配列を返しています。
この結果になった理由について、
/\\d+/g この宣言とは、連続したすべての数字の文字列を検索するということです。
この .matchメソッドと組み合わせて、マッチすると、取得します。
そのため、この文字列では、左から右へ順番にスキャンします。これ（0123）を取得して、これに来ると、数字になっていないため、取得しません。そのように処理を続けて、文字列の最後まで行くまで、止まります。そのため、これらの３つを取得しました。
じゃ、それは、この例のことです。皆さんできましたか？

そのため、この文字列全体を左から右へ順番にスキャンします。
そして、これ（JOHN）を取得しました。ここに来ると、大文字の単語になっていないで、スペースなので、取得しません。文字列の最後まで、そのように処理を続けて、それらの４つが取得できました。
